# dgpsi: Computer Model Emulation Using Gaussian Process Networks

Provides tools for scalable computer model emulation using Gaussian
process networks. The implementations follow Ming & Guillas (2021)
[doi:10.1137/20M1323771](https://doi.org/10.1137/20M1323771) for linked
Gaussian processes, Ming, Williamson, & Guillas (2023)
[doi:10.1080/00401706.2022.2124311](https://doi.org/10.1080/00401706.2022.2124311)
for deep Gaussian processes, Ming & Williamson (2023)
[doi:10.48550/arXiv.2306.01212](https://doi.org/10.48550/arXiv.2306.01212)
for linked deep Gaussian processes, and Ming & Williamson (2026)
[doi:10.1016/j.csda.2026.108485](https://doi.org/10.1016/j.csda.2026.108485)
for generalized deep Gaussian processes. To get started with the
package, see <https://mingdeyu.github.io/dgpsi-R/>.
